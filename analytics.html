📖 HOW THE ANALYTICS DASHBOARD WORKS Reference

WHAT THIS DASHBOARD SHOWS

The Analytics Dashboard analyzes signal validation performance from the SQLite database. It shows how accurate the scanner's HIGH_CONVICTION signals have been over time, helping you understand which conditions produce the best results.

DATA SOURCE

Database: data/wingman.db (SQLite)

API: /api/signals and /api/signals/stats

Update Frequency: Every 30 seconds

MULTI-CHECKPOINT VALIDATION

Each HIGH_CONVICTION signal gets checkpoints at multiple intervals:

4h Checkpoint Short-term signal accuracy - how the signal performs intraday
24h Checkpoint Overnight/next-day accuracy - did the move continue?
7d Checkpoint Swing trade accuracy - longer-term signal validation

OUTCOME DEFINITIONS

WIN Signal moved ≥2% in predicted direction
LOSS Signal moved ≤-2% against predicted direction (drawdown)
BREAKEVEN Signal closed within ±2% of entry (72-hour time stop)

METRICS TRACKED

Peak Gain Maximum % gain reached during signal lifecycle
Max Drawdown Maximum adverse move against signal direction
Left on Table Difference between peak gain and actual exit

ANALYSIS VIEWS

  • By Tier: HIGH_CONVICTION vs TRADEABLE vs WATCH win rates
  • By VIX Regime: Which volatility levels produce best signals
  • By Score Range: Does higher score = better results?
  • By SPY Trend: Bullish vs bearish market context
  • By Direction: Bullish vs bearish signal accuracy

KEY INSIGHTS

Use this dashboard to answer questions like:

  • Should I adjust the score threshold for alerts?
  • Do signals work better in low or high VIX environments?
  • Are bullish or bearish signals more accurate?
  • How much am I leaving on the table by exiting early?
