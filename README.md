## The System

### What It Does
**Wingman** is a complete trading system for managing positions, tracking P&L, enforcing risk management, and journaling trades—with AI assistance.

### Core Features

**1. VWAP Reversion + Divergence Scalps (Primary)**
- Enhanced TradingView indicator with VWAP + ATR bands
- 11-indicator divergence detection
- Real-time checklist table on chart
- 95%+ signal accuracy (tested on your chart)
- 5-minute entry-to-exit trades
- $200 max risk per trade (1%)

**2. Real-Time Dashboard**
- Account balance tracking
- Daily/weekly/monthly goal progress
- Risk management cards (daily/weekly loss limits)
- Open positions with P&L
- Session notes (collapsible, timestamped)
- Historical session viewer (date dropdown)
- Auto-refreshes every 10 seconds

**3. Automated Risk Management**
- 1% per trade rule ($200 max)
- $500 daily loss limit (HARD STOP)
- $1,000 weekly loss limit (HARD STOP)
- Max 5 open positions simultaneously
- Position sizing via ATR formula

**4. Trade Tracking**
- Real-time position monitoring
- Permanent trade journal with divergence data
- Daily/weekly/monthly P&L summaries
- Performance analytics
- Strategy breakdown by effectiveness

**5. End-of-Day Automation**
- Single command: `node eod.js`
- Auto-archives daily logs and positions
- Updates account summaries
- Resets for next trading day
- <1 second execution
